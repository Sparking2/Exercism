# Exercism

My personal solutions to [Exercism](https://exercism.org) coding exercises.

## Overview

This repository contains my solutions to Exercism exercises across three language tracks:
**JavaScript**, **C++**, and **C#**. Each exercise lives under a language folder and
contains one or more numbered iterations, reflecting how the solution evolved over time.

## Repository structure

```
solutions/
├── cpp/            # C++ track
├── csharp/         # C# track
└── javascript/     # JavaScript track
```

Each exercise is organized as:

```
solutions/<language>/<exercise>/<iteration>/<solution-files>
```

- `<exercise>` — the slug of the Exercism exercise (e.g. `leap`, `raindrops`).
- `<iteration>` — the revision number of the solution (e.g. `1`, `2`, `3`).
  Exercises that were reworked have multiple iteration folders.
